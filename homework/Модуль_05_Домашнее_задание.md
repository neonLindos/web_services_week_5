Модуль 05

Тема: Настройка использования Web API, с помощью приложения ASP.NET Core

Цель работы

Разработать клиентское ASP.NET Core приложение, которое взаимодействует с внешним Web API с использованием HttpClient и выполняет основные CRUD-операции.

Задание

Создайте ASP.NET Core приложение TaskManagerClient, которое работает с Web API для управления задачами.

Модель TaskItem должна содержать минимум следующие поля:

Id — идентификатор;

Title — название задачи;

Description — описание;

IsCompleted — признак выполнения.

Требования

Приложение должно реализовать:

Получение списка задач

Отправить GET-запрос к Web API и вывести полученные задачи на странице.

Получение одной задачи

Реализовать получение задачи по её Id.

Пример запроса:

GET /api/tasks/5

Добавление задачи

Создать форму добавления новой задачи и отправлять данные в Web API через POST.

Изменение задачи

Реализовать редактирование существующей задачи через PUT.

Пользователь должен иметь возможность изменить название, описание и статус задачи.

Удаление задачи

Добавить возможность удаления задачи через DELETE.

Перед удалением необходимо запросить подтверждение пользователя.

Работа с HttpClient

Запрещается создавать new HttpClient() непосредственно перед каждым запросом.

Необходимо зарегистрировать клиент через:

AddHttpClient(...)

и получать его через IHttpClientFactory.

Для Web API необходимо настроить именованный HttpClient, указав BaseAddress.

Обработка ответов API

Для каждого запроса необходимо проверять результат выполнения.

Приложение должно корректно обрабатывать как минимум:

200 OK;

201 Created;

400 Bad Request;

404 Not Found;

500 Internal Server Error.

При возникновении ошибки пользователь должен увидеть понятное сообщение, а приложение не должно аварийно завершаться.

Результат работы

В результате должно получиться приложение со страницей примерно следующего содержания:

Список задач

| ID | Название | Статус | Действия |
| --- | --- | --- | --- |
| 1 | Изучить HttpClient | Выполнено | Изменить / Удалить |
| 2 | Реализовать Web API | В работе | Изменить / Удалить |
| 3 | Изучить PATCH | В работе | Изменить / Удалить |

Также должна присутствовать кнопка «Добавить задачу».
