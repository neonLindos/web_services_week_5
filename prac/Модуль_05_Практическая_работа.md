**Тема:** Настройка использования Web API, с помощью приложения ASP.NET Core

## Цель работы

Создать простое ASP.NET Core приложение, которое обращается к Web API с помощью HttpClient, получает и отправляет данные и обрабатывает HTTP-ответы.

## Задание

Необходимо создать клиентское приложение StudentClient, которое взаимодействует с Web API для работы со студентами.

## Модель данных

Создайте модель Student:

```text
Student
----------------
Id
FullName
Group
Course
Email
```

## Часть 1. Подготовка проекта

Создайте ASP.NET Core приложение:

StudentClient

Добавьте следующую структуру:

```text
Models
 └── Student.cs
Services
 ├── IStudentApiService.cs
 └── StudentApiService.cs
Controllers
 └── StudentController.cs
Views
 └── Student
```

## Часть 2. Настройка HttpClient

В Program.cs зарегистрируйте именованный HTTP-клиент:

```csharp
AddHttpClient(...)
```

Настройте:

- имя клиента — StudentApi;
- BaseAddress — адрес Web API.

Для получения настроенного клиента используйте:

IHttpClientFactory

## Часть 3. Создание сервиса

Создайте интерфейс:

IStudentApiService

Добавьте в него методы:

- GetAllAsync()
- GetByIdAsync(int id)
- CreateAsync(Student student)
- DeleteAsync(int id)

Создайте реализацию:

StudentApiService

Получите IHttpClientFactory через Dependency Injection.

В сервисе создавайте настроенный клиент:

```csharp
CreateClient("StudentApi")
```

## Часть 4. Получение списка студентов

Реализуйте первый запрос:

```http
GET /api/students
```

Для выполнения запроса используйте HttpClient.

Полученный JSON необходимо преобразовать в коллекцию:

```csharp
List<Student>
```

Создайте страницу для отображения результата

| ID | ФИО | Группа | Курс | Email |
| --- | --- | --- | --- | --- |
| 1 | Иван Иванов | SE-301 | 3 | ivan@example.com |
| 2 | Анна Петрова | SE-302 | 3 | anna@example.com |
| 3 | Максим Ким | SE-301 | 3 | maxim@example.com |

## Часть 5. Получение студента по ID

Добавьте возможность получить одного студента:

```http
GET /api/students/{id}
```

Например:

```http
GET /api/students/2
```

Отобразите:

- ФИО;
- группу;
- курс;
- Email.

Если студент отсутствует, обработайте:

404 Not Found

и выведите сообщение:

Студент с указанным ID не найден.

## Часть 6. Добавление студента

Создайте форму:

```text
ФИО:        ____________________
Группа:     ____________________
Курс:       ____________________
Email:      ____________________
```

После заполнения формы создайте объект Student.

Отправьте его в Web API:

```http
POST /api/students
```

После успешного добавления вернитесь к списку студентов.

## Часть 7. Удаление студента

Добавьте в таблицу кнопку:

Удалить

При ее нажатии необходимо выполнить:

```http
DELETE /api/students/{id}
```

После успешного удаления повторно запросите список студентов и убедитесь, что запись исчезла.

## Часть 8. Обработка HTTP-ответов

Добавьте проверку результатов запросов.

Обработайте:

- 200 OK
- 201 Created
- 400 Bad Request
- 404 Not Found
- 500 Internal Server Error

Используйте:

IsSuccessStatusCode

или проверку конкретного StatusCode.

При ошибке приложение не должно аварийно завершаться.

## Часть 9. Самостоятельная часть

После выполнения основной части необходимо добавить возможность редактирования студента.

Необходимо:

- Добавить кнопку «Изменить».
- Получить данные выбранного студента через GET.
- Отобразить их в форме.
- Позволить изменить FullName, Group, Course и Email.
- Отправить измененные данные через:

```http
PUT /api/students/{id}
```

После успешного изменения вернуться к общему списку.
