# Практическая работа — Модуль 05

**Тема:** использование Web API из ASP.NET Core через HttpClient.
**Проект:** StudentClient (Student).
**Используемые технологии:** .NET 8, ASP.NET Core MVC, Razor, IHttpClientFactory.

## Как запустить

1. Из корня репозитория запустите учебный API в отдельном терминале:
   ```powershell
   dotnet run --project api/DemoApi.csproj
   ```
2. Запустите клиент:
   ```powershell
   dotnet run --project prac/StudentClient.csproj
   ```
3. Откройте http://localhost:5103. В Visual Studio можно открыть `.csproj` и выбрать профиль `StudentClient`.

API: `http://localhost:5100/api/students`. Адрес задаётся в `appsettings.json`
через `Api:BaseAddress` или переменную `Api__BaseAddress`. Нужен JSON-массив для
списка и JSON-объект для одной записи, без оболочки `data`.
Учебный API хранит данные в памяти; после перезапуска изменения сбрасываются.
HTTP используется для локальной демонстрации. Для развёртывания требуется HTTPS.

## Что реализовано

| Метод | Endpoint | Назначение | Успех | Ошибка |
|---|---|---|---|---|
| GET | `/api/students` | Список | 200 | 500 |
| GET | `/api/students/{id}` | Получение по ID | 200 | 404, 500 |
| POST | `/api/students` | Создание | 201 | 400, 500 |
| PUT | `/api/students/{id}` | Редактирование всех полей | 204 | 400, 404, 500 |
| DELETE | `/api/students/{id}` | Удаление с подтверждением | 204 | 404, 500 |

Есть таблица, поиск по ID, подробности, формы создания/изменения и отдельная
страница подтверждения удаления. Изменения отправляются POST-формами с
антиподдельным токеном. Входные поля проверяются серверной валидацией.
При ошибке API форма сохраняет введённые значения и показывает сообщение.

## Использование IHttpClientFactory

`AddHttpClient("StudentApi", ...)` регистрирует именованный клиент с BaseAddress
и тайм-аутом 10 секунд. Сервис получает его через
`IHttpClientFactory.CreateClient("StudentApi")` в конструкторе. Фабрика управляет
пулом обработчиков соединений; `new HttpClient()` перед запросами не используется.
Общая реализация запросов находится в `../shared/` и подключена в `.csproj`.

## Обработка ответов

Проверяется `IsSuccessStatusCode`: 200/201/204 означают успех подходящей операции.
400 сообщает об ошибке данных, 404 — «Студент с указанным ID не найден.», 500 — о сбое API.
Обрабатываются также другие неуспешные статусы, недоступность API, тайм-аут,
пустой или некорректный JSON. Тело ошибки внешнего сервера пользователю не выдаётся.

## Результат работы

| Возможность | Реализация |
|---|---|
| Чтение | Список и поиск по ID |
| Создание | Форма → POST → обновлённый список |
| Изменение | GET → форма → PUT → список |
| Удаление | Подтверждение → DELETE → список |
| Ошибки | Понятное сообщение без аварийного завершения при ошибке API |
