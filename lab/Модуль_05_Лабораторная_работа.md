> Модуль 05

**Тема:** Настройка использования Web API, с помощью приложения ASP.NET Core

## Цель работы

Научиться вызывать Web API из приложения ASP.NET Core, использовать HttpClient и IHttpClientFactory, отправлять HTTP-запросы и обрабатывать ответы сервера.

## Задание

Необходимо создать клиентское ASP.NET Core приложение, которое взаимодействует с Web API и позволяет управлять списком товаров.

## Модель данных

Создайте модель Product:

```text
Product
----------------
Id
Name
Description
Price
Quantity
```

## Часть 1. Создание проекта

Создайте ASP.NET Core приложение:

ProductClient

Создайте следующие основные компоненты:

```text
Models
 └── Product.cs
Services
 ├── IProductApiService.cs
 └── ProductApiService.cs
Controllers
 └── ProductController.cs
Views
 └── Product
```

## Часть 2. Настройка HttpClient

В Program.cs зарегистрируйте HTTP-клиент через:

```csharp
AddHttpClient(...)
```

Настройте для него:

- имя клиента;
- BaseAddress Web API.

Для создания клиента используйте IHttpClientFactory.

Не создавайте новый экземпляр HttpClient для каждого отдельного запроса.

## Часть 3. Создание сервиса

Создайте интерфейс:

IProductApiService

В нем определите методы для взаимодействия с Web API:

- GetAllAsync()
- GetByIdAsync(int id)
- CreateAsync(Product product)
- UpdateAsync(Product product)
- DeleteAsync(int id)

Создайте класс:

ProductApiService

который реализует данный интерфейс.

Внедрите IHttpClientFactory через конструктор.

## Часть 4. Получение списка товаров — GET

Реализуйте отправку запроса:

```http
GET /api/products
```

Полученный JSON необходимо преобразовать в коллекцию объектов Product.

Создайте страницу, отображающую товары в таблице.

Пример:

| ID | Название | Цена | Количество |
| --- | --- | --- | --- |
| 1 | Notebook | 350 000 | 5 |
| 2 | Mouse | 8 000 | 15 |
| 3 | Keyboard | 15 000 | 10 |

Проверка: при открытии страницы данные должны загружаться через Web API.

## Часть 5. Получение товара по ID — GET

Реализуйте получение одного товара:

```http
GET /api/products/{id}
```

Добавьте возможность указать Id товара и получить подробную информацию о нем.

Обработайте ситуацию, когда API возвращает:

404 Not Found

В этом случае пользователь должен увидеть сообщение:

Товар не найден.

## Часть 6. Добавление товара — POST

Создайте форму:

```text
Название:       ____________
Описание:       ____________
Цена:           ____________
Количество:     ____________
             [Добавить]
```

После нажатия кнопки необходимо сформировать объект Product и отправить его в Web API:

```http
POST /api/products
```

После успешного создания пользователь должен вернуться к списку товаров.

## Часть 7. Изменение товара — PUT

Добавьте кнопку:

Изменить

рядом с каждым товаром.

После выбора товара откройте форму с его текущими данными.

Пользователь должен иметь возможность изменить:

- название;
- описание;
- цену;
- количество.

Измененные данные отправьте через:

```http
PUT /api/products/{id}
```

После успешного обновления снова отобразите список товаров.

## Часть 8. Удаление товара — DELETE

Добавьте кнопку:

Удалить

При нажатии необходимо отправить:

```http
DELETE /api/products/{id}
```

После успешного удаления обновите список товаров.

## Часть 9. Обработка ответов Web API

При выполнении запросов проверяйте результат HTTP-запроса.

Обработайте как минимум:

- 200 OK
- 201 Created
- 400 Bad Request
- 404 Not Found
- 500 Internal Server Error

При возникновении ошибки приложение не должно аварийно завершаться.

Пользователь должен получить понятное сообщение об ошибке.

## Часть 10. Проверка работы

Продемонстрируйте преподавателю следующий сценарий:

- Запустить Web API.
- Запустить клиентское приложение.
- Получить список товаров.
- Получить один товар по Id.
- Добавить новый товар.
- Убедиться, что он появился в списке.
- Изменить созданный товар.
- Проверить сохранение изменений.
- Удалить товар.
- Убедиться, что товар исчез из списка.
